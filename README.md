# Summary
A Console Based File Explorer Written in C++
Current Function: File View
Possible Future Features: Opening a selected file

# Navigation
Up/Down Arrow - Navigation
Enter - Opening directory
Q - Quit

# Imortant Librarys
<filesystem> - Used to get directory/paths
<conio.h> - Used to get keyinputs (_getch())
<windows.h> - Functions and terminal size
<format> - String formatting (std::format)
